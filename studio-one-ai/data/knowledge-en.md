## Common Operations

### Duplicate a Track
- Right-click track > "Duplicate Track" or "Duplicate Track (with Events)"
- For single events: select and press Ctrl+D (Win) / Cmd+D (Mac)

### Add Effect (e.g., Reverb) to Audio
1. Open Browser (F5) > "Effects" category
2. Drag desired effect (Room Reverb / Open AIR) onto target track
3. Or click track's "Insert" slot in Console (F3) and select effect

### Change Tempo Mid-Song (Tempo Track)
1. Right-click empty space in track list > "Add Tempo Track" (or View menu)
2. Click tempo track to add tempo points, adjust values
3. For global base tempo: Double-click tempo display in transport bar and enter value

### Export / Bounce / Mixdown
- Menu: Song > "Export Mixdown" (or Song > "Mix Down")
- Shortcut: Ctrl+E (Win) / Cmd+E (Mac)
- Set loop range or full song, choose format (WAV/MP3), bit depth, sample rate

### Quantize MIDI
1. Select MIDI event or notes
2. Press Q to apply quantize
3. Fine-tune via Quantize panel (Inspector or View menu) — set grid value

### Split / Merge Events
- Split: Select event, position playhead, press Alt+X (Win) / Opt+X (Mac)
- Merge: Select multiple events > right-click > "Glue" or Merge

### Add Virtual Instrument
1. Open Browser (F5) > "Instruments"
2. Drag instrument (Mai Tai, Presence XT, Impact XT, etc.) into arrange view
3. Instrument track is created automatically

### Fade In / Out
- Drag top-left or top-right corner of audio event to create fade
- Adjust fade curve by dragging the fade handle

## Studio One 7 Main Instruments & Effects

**Instruments**
- Mai Tai — Analog modeling synth
- Presence XT — Sample-based instrument
- Impact XT — Drum sampler
- Sample One XT — Sampler / recording tool
- Mojito — Monophonic synth

**Effects**
- Pro EQ — Equalizer
- Compressor / Limiter / Multiband Dynamics
- Open AIR — Convolution reverb / Room Reverb
- Analog Delay / Beat Delay
- Ampire — Guitar amp simulator
