## 1. 完了判定ロジック（マルチシグナル対応）

### 判定パターン
```
判定パターン:
├─ Slack: メッセージ「✅完了」or スレッド内で "done/完了"
├─ Teams: タスク status 変更 → 「完了」
├─ Zoom: チャット＆メモに "[DONE]" タグ
├─ Notion: Checkbox ✓ or Status → "Done"
└─ Asana: Task status → "Complete"

判定ルール: いずれか1つのシグナルで「完了」確定
```

## 3. AI検証エンジン（誤検知排除）

### 4段階検証プロセス

**ステップ1: 自動検出**
- Slack「完了」メッセージ検出

**ステップ2: 文脈確認（NLP）**
- 「これ完了した」の意図確認
- 絵文字/トーン分析

**ステップ3: メタデータ検証**
- ユーザーID一致確認
- タイムスタンプ逆算チェック
- 同一タスク複数メッセージ検出

**ステップ4: 誤検知フラグ立て**
- 人間が最終確認（コンフーム必須）

## 4. レポート生成（3階層）

### 個人レベル
```

├─ 平均完了時間: 1.2日（締切比）
├─ 期限超過: 1件
└─ 最速完了: "Design review feedback" (3時間)
```

├─ メンバー別: Alice 95% / Bob 78% / Carol 89%
├─ ボトルネック: "Legal approval" (平均遅延 2.1日)
