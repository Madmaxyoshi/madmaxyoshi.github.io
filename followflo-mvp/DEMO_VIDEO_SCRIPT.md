# FlowFllo MVP デモビデオ スクリプト（5分）

## ビデオ構成
- **オープニング**: FlowFllo のロゴ＆タイトル（15秒）
- **シーン1**: アクションアイテム作成（60秒）
- **シーン2**: 完了シグナル検出（60秒）
- **シーン3**: AI検証エンジン（60秒）
- **シーン4**: ダッシュボード & メトリクス（60秒）
- **シーン5**: 自動エスカレーション（60秒）
- **クロージング**: ビジネスモデル＆CTA（15秒）

---

## シーン1: アクションアイテム作成（60秒）

**背景**: Slack ワークスペースの開画面  
**ナレーション**: 「会議でアクションアイテムが出たら、FlowFllo で登録します」

**スクリーンショット順序**:

1. Slack チャネル #general を開く（5秒）
2. メッセージ入力欄に以下を入力:
   ```
   /followflo create "API設計ドキュメント作成" @engineer1 deadline:2026-06-07
   ```
   （入力画面を見せる、15秒）

3. Enter キーを押す（5秒）

4. FlowFllo からの確認メッセージが表示される:
   ```
   ✅ アクションアイテムを記録しました
   • タスク: API設計ドキュメント作成
   • 担当者: @engineer1
   • 期限: 2026-06-07
   ```
   （確認画面を見せる、10秒）

5. 同時に `/followflo list` コマンドで一覧を表示（15秒）:
   ```
   📋 未完了タスク一覧 (1件)
   • API設計ドキュメント作成 (@engineer1) - 2026-06-07
   ```

**ナレーション**: 「期限、担当者、タスク名が自動記録され、待機状態に入ります」

---

## シーン2: 完了シグナル検出（60秒）

**背景**: 同じ Slack チャネル  
**ナレーション**: 「では、API設計ドキュメント作成を完了した報告が来たとします」

**スクリーンショット順序**:

1. engineer1 ユーザーが以下のメッセージを投稿（シミュレーション、10秒）:
   ```
   ✅ API設計ドキュメント完成しました！
   ```
   （メッセージを見せる）

2. FlowFllo が自動検出して反応（アニメーション効果、10秒）:
   ```
   ✅ @engineer1 が 'API設計ドキュメント作成' を完了しました！
   ✅ 自動認証されました
   信頼度: 95%
   ```

3. または、代替シナリオ - リアクションでの検出（20秒）:
   - engineer1 が自分の完了メッセージに ✅ リアクションを付ける
   - FlowFllo が検出して同じ確認メッセージを返す

4. 同時に、以下が舞台裏で実行される（ログ表示、20秒）:
   ```
   Stage 1: キーワード検出 ✅ (✅ 検出)
   Stage 2: 文脈確認 ✅ (タスク名OK, ユーザーOK)
   Stage 3: 証拠記録 ✅ (Hash: abc123...)
   → 検証完了・自動承認
   ```

**ナレーション**: 「複数の完了シグナル（✅ 絵文字、完了テキスト、リアクション）に対応し、自動検出します」

---

## シーン3: AI検証エンジン（60秒）

**背景**: Dashboard または ログビューア  
**ナレーション**: 「FlowFllo は 4段階の検証エンジンで、誤検知を防ぎます」

**スクリーンショット順序**:

1. 4段階検証フローの図解（30秒）:
   ```
   Stage 1: 自動検出
   └─ 完了キーワード: ✅ 完了 done finished
   
   Stage 2: 文脈確認
   └─ タスク名マッチング + ユーザー割り当て確認
   └─ 信頼度スコア: (タスク名: +0.4) + (ユーザー: +0.6) = 信頼度
   
   Stage 3: 証拠記録
   └─ SHA256 ハッシング
   └─ タイムスタンプ自動保存
   └─ メッセージテキスト、スクリーンショット記録
   
   Stage 4: 人間確認
   └─ 信頼度 < 0.8 の場合は要確認フラグ
   └─ マネージャーダッシュボードで最終確認
   ```

2. テーブルで異なるシナリオの信頼度比較（30秒）:
   | メッセージ | タスク名 | ユーザーOK | 信頼度 | 結果 |
   |----------|--------|----------|------|------|
   | ✅ API設計完了 | ✅ | ✅ | 95% | 自動承認 |
   | ✅ 完了 | ❌ | ✅ | 60% | 要確認 |
   | API設計準備中 | ✅ | ✅ | 0% | 却下 |

**ナレーション**: 「検証信頼度に応じて、自動承認または人間確認に振り分けます」

---

## シーン4: ダッシュボード & メトリクス（60秒）

**背景**: Slack ダッシュボード Modal  
**ナレーション**: 「個人、チーム、マネージャーレベルの詳細なメトリクスが自動生成されます」

**スクリーンショット順序**:

1. `/followflo dashboard` コマンド実行（5秒）

2. ダッシュボード Modal が表示される（30秒）:
   ```
   📊 FlowFllo ダッシュボード
   
   【個人の成績】
   完了率: 85% (17/20)
   平均完了時間: 2.3日
   
   【チームランキング】
   1. Alice (92%)
   2. Bob (85%)
   3. Carol (78%)
   
   【期限超過タスク】
   ⚠️ データベース設計 (@David) - 3日超過
   ⚠️ テスト計画書 (@Eve) - 1日超過
   ```

3. 個人メトリクスの時系列グラフ表示（15秒）:
   - 完了率の推移（週単位）
   - 完了時間の平均

4. チームランキング表の更新（10秒）

**ナレーション**: 「個人・チーム・遅延タスクのメトリクスが一目瞭然。マネージャーは全体状況を掌握できます」

---

## シーン5: 自動エスカレーション（60秒）

**背景**: Slack チャネル（複数のチャネルを交互に表示）  
**ナレーション**: 「期限超過タスクは、自動的に段階的にエスカレーションします」

**スクリーンショット順序**:

1. タスク作成直後の状態（5秒）:
   ```
   📌 新規タスク:「競合分析レポート」
   期限: 2026-06-05
   担当: @David
   状態: 進行中
   ```

2. 期限の1日前（T-1日）- リマインド通知（15秒）:
   ```
   【#general チャネル】
   ⏰ リマインド: @David - "競合分析レポート" の期限は明日です (2026-06-05)
   ```

3. 期限を過ぎた24時間後（T+24h）- マネージャー通知（15秒）:
   ```
   【#general チャネル】
   ⚠️ エスカレーション Level 2: @manager - "競合分析レポート" (@David) が24時間超過しています
   ```

4. 3日超過時（T+3日）- エグゼクティブレポート（15秒）:
   ```
   【#c-level チャネル】
   📊 Executive Report: 2件のタスクが3日以上超過
   • "競合分析レポート" (責任者: @David) - 超過: 3日
   • "予算計画" (責任者: @Sarah) - 超過: 5日
   ```

5. エスカレーションレベルの進行図（10秒）:
   ```
   Status: pending
   Escalation: Level 0 → Level 1 (T-1) → Level 2 (T+24h) → Level 3 (T+3d)
   ```

**ナレーション**: 「期限超過は自動的に段階的にエスカレーションされ、全組織に可視化されます。誰もタスク漏れに気づかないことはありません」

## ビデオ録画技術仕様

### 推奨設定
- **解像度**: 1920x1080 (Full HD)
- **フレームレート**: 30fps
- **ビットレート**: 5Mbps
- **コーデック**: H.264
- **ファイル形式**: MP4
- **総長**: 約 5分 30秒

### 録画ツール候補
1. **macOS**: QuickTime Player + ScreenFlow
2. **Windows**: OBS Studio + Windows 10 Game Bar
3. **Linux**: OBS Studio + FFmpeg
4. **Web**: Loom, Screencastify

### ナレーション
- 日本語音声で清潔に
- バックグラウンド音楽: 静かなテック系BGM (ロイヤリティフリー)
- 音声レベル: -3dB で調整
