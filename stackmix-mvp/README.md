# StackMix MVP

**音楽版 Frame.io** — 音楽制作チームのコラボレーションプラットフォーム

## コンセプト

Frame.io が映像制作のレビュー・承認ワークフローを変えたように、
StackMix は音楽制作の「レビュー・フィードバック・バージョン管理」を変える。

## ターゲット

- 音楽プロデューサー × アーティスト
- レコードレーベル × プロデューサー
- 映像制作会社 × 作曲家（BGM発注）
- ゲーム会社 × 音楽チーム

## 主要機能（予定）

1. **タイムライン上コメント** — 波形の特定秒にコメントを付ける
2. **バージョン管理** — v1, v2, v3... の比較再生
3. **承認ワークフロー** — クライアントが「承認」「修正依頼」を明示
4. **ステム管理** — トラック別（ドラム/ベース/ボーカル等）にアップロード
5. **DAW連携** — Logic Pro / Ableton Live / Pro Tools プラグイン

## ビジネスモデル

- $19/ユーザー/月（プロ）
- $49/ユーザー/月（スタジオ）
- ストレージ課金（追加容量）

## 技術スタック（予定）

- Frontend: React + TypeScript + Wavesurfer.js
- Backend: Node.js + Express
- Storage: AWS S3
- DB: PostgreSQL
